## 🌐 About the Project

**MZ CYBER SUITE V9** is an experimental, web-based cybersecurity platform designed to bring a collection of security checks, intelligence tools and practical utilities together in one dashboard.

The platform is accessed directly through a web browser. Users do not need to download or install the application on their computers.

The project explores how accessible security tools can be combined into a single, straightforward interface.

## 🔗 Access the Website

**Live platform:** [https://mz-cyber-suite-v9.onrender.com](https://mz-cyber-suite-v9.onrender.com)

Visit the website to access the platform and explore its available features.

## 🛡️ Platform Features

The platform brings together different categories of security-related tools.

### Network & Infrastructure Checks

- Basic network security checks
- Public IP information
- DNS information
- WHOIS lookups
- Standard port checks

### Public Intelligence

- Public search links
- Username searches
- Name-based public search links
- Search engine intelligence
- External breach-checking resources

### Breach Intelligence

- Planned Have I Been Pwned API integration
- Email breach checking, subject to API configuration
- Breach names and dates
- Exposed information categories
- Security recommendations

### Security Utilities

- Practical security tools
- Information analysis utilities
- Supporting tools for everyday security tasks

*Feature availability may change as development continues. Not every listed feature is necessarily operational yet.*

## 🔐 Security & Privacy

Security and responsible use are important parts of the project.

The platform includes:

- Account-based access
- Owner and standard-user roles
- Protected administrative functionality
- Rate-limited security operations
- Audit logging
- Server-side access controls

Users should only investigate information belonging to themselves or information they have explicit permission to assess.

The platform is not designed to access stolen databases, expose private passwords or obtain unauthorised personal information.

## 🧪 Experimental Development

It is being developed to explore:
